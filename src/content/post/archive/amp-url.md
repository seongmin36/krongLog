- AMP URL : mobile에서 웹페이지를 더 빠르게 열 수 있게 만든 구글 가속 모바일 페이지의 주소다.
- 특징
    - 빠른 속도 : 불필요한 요소를 없애 모바일 로딩 속도를 크게 높인다.
        - 여기서 불필요한 요소는 뭘까?
            - 무거운 JS 코드. 예를 들어, 화려한 효과, 복잡한 사용자 추적 스크립트, 위젯 등이 대량의 JS 사용을 해 로딩을 느리게 만든다.
이를 AMP는 외부 JS 실행을 원칙적으로 금지하며, AMP 전용 라이브러리(비동기 로딩)만 허용한다.
            - 복잡한 CSS. 예를 들어, 웹사이트를 예쁘게 꾸미기 위해 수많은, 사용하지 않은 디자인 코드(CSS)를 한꺼번에 불러온다.
AMP는 CSS용량을 최대 50kb로 제한하여, 반드시 HTML 내부에 직접 작성하도록 한다.
            - 통제되지 않는 무거운 미디어·광고. 예를 들어 페이지가 다 열리기도 전에 고용량 이미지나 움직이는 배너 광고가 한꺼번에 로딩되면서 화면이 버벅거린다.
이를 AMP는 이미지를 lazy-loading을 걸고, 광고 크기를 미리 지정해두어 로딩 중에 layout shift를 막는다.
    - 구글 캐시 주소 : 일반 웹주소와 달리 ://google.com… 같은 형태나 별도의 캐시 경로를 사용해 구글 서버에서 미리 불러온다.
    - 형태 : 보통 원본 주소에 /amp가 붙거나 amp.주소 형태를 띈다.
