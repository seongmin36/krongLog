- 기업이나 기관이 사이버 위협으로부터 자산을 보호하기 위해 사용하는 보안 지침이자 모범 사례의 청사진이다.
- 가장 널리 쓰이는 표준 : NIST CSF 2.0
  - NIST CSF 2.0의 6대 핵심 기능
    - 거버넌스 (Govern) : 조직의 보안 전략, 정책, 공급망 위험 관리 책임을 수립하고 감독한다.
    - 식별 (Identify) : 자산, 시스템, 데이터 및 보안 취약점을 파악하고, 평가한다.
    - 보호 (Protect) : 데이터 보호 및 접근 제어 등 위협을 막기 위한 안전장치를 구현한다.
    - 감지 (Detect) : 네트워크 침입이나 이상 징후 등 보안 사고를 실시간으로 찾아낸다.
    - 대응 (Respond) : 보안 사고가 발생했을 때 피해를 최소화하도록 격리하고 조치한다.
    - 복구 (Recover) : 공격으로 중단된 서비스와 시스템을 정상 상태로 신속하게 되돌린다.

왜 필요할까?

- 공통 언어 제공 : IT 전문가부터 경영진까지 보안 수준과 위험을 쉽게 이해하고 소통할 수 있다.
- 맞춤형 적용 : 특정 기술이나 장비를 강제하지 않으므로, 소기업부터 글로벌 대기업까지 규모에 맞게 변형하여 쓸 수 있다.
- 격차 분석(Gap Analysis) : 현재 조직의 보안 상태(Current Profile)와 목표 상태(Target Profile)를 비교하여 부족한 점을 집중적으로 보완하게 해준다.
