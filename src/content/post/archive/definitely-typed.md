- Definitely Typed(DT)는 TypeScript를 사용할 때 자바스크립트 라이브러리의 타입 정의를 제공하는 거대한 커뮤니티 오픈소스 저장소다.
    - 존재 이유? : 대다수의 레거시 또는 순수 JS 라이브러리는 TypeScript 타입을 내장하지 않는다.
이를 해결하기 위해 커뮤니티가 직접 .d.ts 선언 파일을 만들어 모아둔 곳이 바로 ‘DT’다.
    - DX 측면 : 이를 설치하면 타입스크립트 컴파일러가 타입을 검증할 수 있고, 코드 에디터에서 자동 완성 및 타입 검사 혜택을 누릴 수 있다.
- 의문점? : js → ts 마이그레이션 하지 않고, ts처럼 사용 가능한가? 이건 총 3가지 방법이 있다.
    - 1. 코드 상단에 @ts-check 추가 : 이 ‘// @ts-check’ 주석을 달면, 에디터가 해당 파일을 ts처럼 취급하여 오류를 잡아준다.
    - 2. JSDoc 주석으로 타입 정의
    - 3. @types 패키지(DT)와 조합 : 외부 js 라이브러리를 사용할 때도 JSDoc과 @types를 조합하면 js 파일 안에서 완벽한 자동 완성을 지원받을 수 있다.
