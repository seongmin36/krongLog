- 원시 타입(Primitive Type) : 하나의 값만 저장하는 타입
  - number
  - string
  - boolean
  - null
  - undefined
  - 변수의 이름 뒤에 :(콜론)으로 타입을 작성해서 변수의 타입을 선언하는 것을 타입 주석(type annotation)이라고 한다.
