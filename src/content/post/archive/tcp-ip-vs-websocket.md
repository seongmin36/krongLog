- TCP/IP: OSI 4계층의 전송(transport)계층이고, 순차적 양방향 통신이 가능한 전송 프로토콜이다. 바이트스트림을 통한 데이터 전송을 사용한다. 클라이언트-서버, 앱-서버, pc-pc 등 네트워크 통신의 기반이다.
- WebSocket: OSI 7계층의 애플리케이션(Application)계층이고, TCP 계층 위에서 동작한다. 따라서 순차적, 재전송, 신뢰성의 특징을 가진 TCP의 장점을 모두 갖고있다.
- 즉 TCP/IP와 WebSocket은 따로 구분하는 개념이 아니라, 각 상황에 따라 선택한다.
    - TCP/IP를 사용하는 경우 : 게임 서버, 서버-서버 간 커스텀 프로토콜, DB, 브로커, 프록시같은 소프트웨어에 사용된다.
        - 이유는 패킷 구조를 직접 설계가 가능하고, 텍스트 대신 바이너리 최적화가 가능하다. 또한 불필요한 웹 계층을 사용하지 않고, 매우 세밀한 성능/프로토콜 제어 가능의 이유로 꼽는다.
    - WebSocket을 사용하는 경우 : 채팅, 실시간 알림, 실시간 시세 스트리밍 등에서 사용된다.
        - 이유는 브라우저에서 쉽게 사용이 가능한 양방향 통신이고, 한 번 연결을 시도하고 성공하면, 연결이 유지되어 polling, long polling보다 효율적이다.
