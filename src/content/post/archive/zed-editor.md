- Zed라는 라이브러리를 처음 접해보았다. Astro 공식문서를 파헤치면서 열심히 보면서 Zed라는 IDE가 Rust언어로 매우 빠른 속도로 고성능 멀티플레이어 코드 편집기라는 것을 보았다.
- 어딘가 낯이 익다 싶더니, 다른 현직자분도 zed를 사용하는 것을 본적이 있다. 현재 나는 vscode기반 cursor를 사용중인데, 도대체 어떤 부분이 좋은 것일까? 직접 설치하여 사용해보았다.
    - 1. 파일 검색이 매우 빨랐다. cursor를 주로 사용하는 입장으로서 약간의 딜레이가 있었는데 전혀 느껴지지 않을 정도로 빨랐다.
    - 2. 직접 사용해볼 기회는 없었지만, 멀티 플레이어 코드 편집기기 때문에 채널, 음성, 노트, 프로젝트 공유 같은 협업 흐름을 공식 기능으로 제공한다.
    - 3. cursor와 마찬가지로 ai 기능이 탑재되어있다. (요즘엔 이 기능이 없는게 이상할 정도)
- 뭐 오늘(2026.02.23) 처음 사용중이지만, cursor와 큰 체감은 되지 않는다.
- zed를 써보면서 새로 알게된 것.
    - reddit이나 다른 vscode->zed로 넘어간 사람들의 말로는 Vim과 emacs 설정이 아직 부족하다는 얘기가 있어서 간단히 알아보았다.(요즘엔 또 괜찮다는 말이 있다.)
        - vim: 터미널을 통해 텍스트 편집이 가능한 편집기이다. 총 3가지의 모드로 이루어져있다.
            - 1. 읽기모드 : 초기에 들어갔을 때의 모드이다.
            - 2. 입력모드 : i를 누르면 입력모드에 들어간다. 텍스트를 입력 가능한다.
            - 3. 명령모드 : esc를 누르면 들어갈 수 있다. 나갈떄는 :q, :wq, 등등..
        - emacs: 현대 코드 에디터/IDE 문화에 큰 영향을 준 조상급 에디터
