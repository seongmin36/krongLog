# React 19의 새로운 훅과 서버 컴포넌트 패턴 정리

React 19에서는 여러 새로운 훅과 서버 컴포넌트 관련 기능이 추가되었습니다.

## 새로운 훅들

### useOptimistic

낙관적 업데이트를 쉽게 처리할 수 있는 훅입니다.

### useFormStatus

폼 제출 상태를 추적하는 훅입니다.

## 서버 컴포넌트 패턴

서버 컴포넌트는 서버에서만 실행되어 번들 크기를 줄이고 성능을 개선합니다.
